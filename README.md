# 📱🚀 TechNews Today - Portal de Notícias Tech

Projeto desenvolvido como solução do **Desafio 10** do curso de Desenvolvimento Web.

## 🎯 Objetivo
Transformar a estrutura semântica HTML em um portal moderno, escuro e responsivo utilizando CSS sem frameworks ou JavaScript.

## 🛠️ Tecnologias e Recursos Utilizados
- **HTML5 Semântico:** `<header>`, `<main>`, `<article>`, `<section>`, `<details>`, `<summary>`, `<iframe>` e `<form>`.
- **CSS3 Moderno:**
  - Glassmorphism (`backdrop-filter: blur()`)
  - Texto com gradiente (`background-clip: text`)
  - Layout flexível com **CSS Grid**
  - Cabeçalho fixo com `position: sticky`
  - Responsividade para telemóvel via **Media Query**
